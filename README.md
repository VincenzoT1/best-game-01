## Overview
**NEON HORIZON: VOID ASSAULT** is an arcade action space-combat rogue-lite running in pure HTML5 Canvas and Web Audio API. Built with high-fidelity neon aesthetics, responsive Newtonian flight controls, multi-tier enemy waves, weapon loadout evolutions, and an epic climactic Void Dreadnought boss encounter.

### Features
- **Fluid Combat & Flight**: Newtonian inertia, 360-degree mouse targeting, dynamic screen-shake, and particle blast physics.
- **Weapon System**: Plasma Blasters, Scatter Cannon, Seeking Missiles, and tactical EMP Smart Bombs (`Space` key).
- **Progressive Enemy Waves**: Scout interceptors, heavy assault cruisers, cloaking stealth mines, and the multi-phase Void Dreadnought.
- **Procedural Sound Architecture**: 100% self-contained Web Audio API synthesizer creating retro-futuristic laser fire, engine hum, explosions, and shield alarms without external network assets.
- **Zero Build / Static Delivery**: Pure ES modules loading offline in any modern desktop browser.

## Controls
- `W`, `A`, `S`, `D` / Arrow Keys: Ship Thrusters & Vectoring
- `Mouse`: Aim Targeting Reticle
- `Left Click` / Hold: Fire Primary Battery
- `Space` / `Right Click`: Release EMP Void Bomb
- `Escape` / `P`: Pause Simulation
